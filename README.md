# bilal.cv

موقع سيرة ذاتية مصمّم للهاتف لبلال زكريا الخواجه: الخبرات العملية، الشهادات التدريبية، والأعمال البرمجية (QB).

- موقع ثابت (HTML/CSS/JS) بدون أي أدوات بناء، يعمل مباشرة على GitHub Pages.
- كل المحتوى في `data.js`. لإضافة مشاريع QB أضفها إلى المصفوفة `projects`.
- ملفات الشهادات في `certificates/` والصور المصغّرة في `certificates/thumbs/`.
