# bilal.cv

موقع السيرة الذاتية لمحمد بلال زكريا الخواجة. موقع ثابت (HTML/CSS/JS) يعمل على GitHub Pages دون أي أدوات بناء.

- `index.html`: الصفحة الرئيسية (نبذة، الخبرات، المهارات، برمجيات QB، الشهادات، التواصل).
- `certificates.html`: صفحة جميع الشهادات مع التصفية حسب المجال.
- `script.js`: الحركات والأزرار. **رقم الجوال يُكتب في أول سطرين من هذا الملف** (`PHONE` و`PHONE_DISPLAY`).
- `style.css`: التصميم، ويتضمن تنسيق الطباعة (زر "تحميل PDF" يطبع السيرة كاملة).
- `certificates/`: ملفات الشهادات، و`projects/`: شعارات مشاريع QB.
