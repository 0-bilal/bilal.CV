# bilal.cv

السيرة الذاتية لبلال زكريا الخواجه كموقع إلكتروني بتصميم ورقة A4 تقليدية، يناسب الهاتف والكمبيوتر ويُطبع كملف PDF من صفحتين.

- صفحة HTML ثابتة واحدة (`index.html`) مع `style.css`، بدون أي أدوات بناء، وتعمل على GitHub Pages.
- لتعديل المحتوى عدّل `index.html` مباشرة.
- ملفات الشهادات في `certificates/` وشعارات مشاريع QB في `projects/`.
